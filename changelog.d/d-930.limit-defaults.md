### Changed
- Container limits are no longer required before captions start. Without them,
  Cassini Live sizes itself from a default budget (at most 4 CPUs and the
  engine's recommended memory, each capped at half the host), so a store
  install works without `docker update` and keeps working after app updates.
  Limits an administrator sets still win, and the settings page and `/status`
  now show the active budgets, their source, and the command that enforces
  the stronger kernel protection.
- Whistle is refused on hosts whose default CPU budget falls under its 2-CPU
  minimum (for example 2-CPU hosts with no CPU limit), with the fix named;
  Nemotron still runs there.
