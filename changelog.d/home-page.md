### Added
- Cassini Live has an entry in Nextcloud's app menu, with the same icon as Cassini. It opens a home page for every logged-in user: three steps to captions, with the "Live transcript" bookmark to drag to the bookmarks bar, a picture of where it goes and a copy fallback. Administrators also see what is left to set up after installation (Talk connection, container limits, speech engine), which updates by itself, and links to the settings and diagnostics pages.
