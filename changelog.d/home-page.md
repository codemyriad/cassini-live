### Added
- Cassini Live has an entry in Nextcloud's app menu, with the same icon as Cassini. It opens a home page for every logged-in user, in Cassini's light and dark themes: add the "Live transcript" bookmark once per browser (drag it to the bookmarks bar, or copy it on a phone), then click it in a call, with a picture for each step. Administrators also see what is left to set up after installation (Talk connection and container limits, then the speech engine starts) and, once captions are ready, links to the settings and diagnostics pages.

### Removed
- The separate page for picking up the transcript bookmark (`…/proxy/<app id>/panel/`) is gone: the bookmark is on the Cassini Live page. The whole-panel-in-one-bookmark variant that page offered is no longer handed out.
