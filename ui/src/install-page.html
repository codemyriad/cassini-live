Cassini Live transcript panel

A scrollable live transcript for Talk calls — including your own lines.

Install

  1. Show your browser's bookmarks bar (Ctrl/⌘+Shift+B).
  2. Drag this button onto the bar: 📝 Live transcript
  3. Join a Talk call, turn on closed captions, then click the bookmark. Click it again to close the panel.

Can't drag? and paste it as the URL of a new bookmark.

How it works

The bookmark injects this app's panel script into the Talk page, same-origin through Nextcloud's App API proxy. The panel listens to the captions Talk already receives and renders them as a scrollable, speaker-grouped transcript. Transcript text is AI-generated. Nothing is stored: the panel shows what was said while it was open, and forgets it when the call page closes.
